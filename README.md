# LumenSize — Editorial Image Resizer, Perspective Corrector & Optimizer

A browser-based image workspace built with React, Tailwind CSS, and HTML5 Canvas. All processing runs 100% locally on the client without uploading images to any server.

---

## Key Features & Architecture

### 1. Robust Zoom & Canvas Viewport (Zero Clipping)
- **Isolated Viewport & Scaled Stage**: The canvas viewport container is strictly isolated from the transformed image stage layer.
- **Center-Anchored Transform**: Image stage uses `transformOrigin: 'center center'` and centers inside the viewport. Zoom magnification smoothly scales the image from 15% to 600% without parent overflow clipping.
- **78% Initial Fit Occupancy**: On first load and when clicking **Fit**, the image scales to occupy ~78% of the available canvas area while preserving its aspect ratio, leaving comfortable margins on all sides.
- **Responsive ResizeObserver**: Dynamically recalculates fit scale on window resize or panel toggles.

### 2. Unified Target File Size Search (Compression & Automatic Safe Padding)
- **Single Target Range**: Enter a Min and Max target size (KB or MB) in one prominently highlighted section.
- **Intelligent Two-Way Optimizer**:
  1. If the file is above the maximum limit, it performs binary search on compression quality and optional dimension scaling.
  2. If the file is below the minimum limit, it automatically applies safe, format-compliant metadata padding (`padBlobToFileSize`) to reach the required size.
- **Zero Simulation**: Always measures and reports the exact byte size generated by browser encoding.

### 3. Streamlined Dimensions & Output Controls
- **Default Unit `cm`**: Centimeters by default, with instant switching to `in` or `px`.
- **DPI Directly Below Dimensions**: Configurable DPI/PPI input placed immediately under Width and Height fields.
- **Integrated Quality Slider**: Lossy compression quality control is embedded directly inside the Dimensions section.
- **Simplified Canvas Fitting**: Minimal **Fit** and **Fill** buttons with an unlabelled color swatch defaulting to `#FFFFFF` (white).
- **Clean Layout**: Presets and repetitive explanations removed from the editing panel for a focused, calm editing experience.

### 4. Coordinated Themes in Preferences
- Themes moved cleanly into the **Preferences (Settings)** modal accessible from the top bar.
- Five distinct palettes with visual swatches (Base, Panel, Border, Accent):
  - **Warm Paper** (Light): Warm parchment paper (`#fbf9f4`), dark ink typography, and vivid vermilion accent (`#d94a26`).
  - **Obsidian Ember** (Dark): Obsidian slate (`#111215`), deep panels, and ember vermilion accent (`#e8562e`).
  - **Clean Studio** (Light): Gallery white (`#f4f5f8`), crisp charcoal, and cobalt accent (`#2563eb`).
  - **Nordic Slate** (Dark): Cool graphite (`#0f1319`), arctic slate, and cyan/ice-blue accent (`#0284c7`).
  - **Editorial Sage** (Dark): Dark forest charcoal (`#131714`), sage borders, and warm brass accent (`#d97706`).
- Persisted across browser sessions in `localStorage`.

### 5. Sticky Download Button
- The **Download image** button is permanently visible and sticky at the bottom of the control panel (`sticky bottom-0`).
- Stays easily reachable at all times without scrolling or obscuring the canvas workspace.

### 6. Non-Destructive Edit Timeline (Left Sidebar)
- Slim collapsible left sidebar tracking each committed edit step.
- Full non-destructive travel: jumping backwards preserves future steps so you can step back and forth freely.
- Global keyboard shortcuts (`Ctrl+Z` / `Ctrl+Y`).

### 7. On-Canvas Crop & 4-Corner Perspective Homography
- **Boundless Rectangular Crop**: 8-handle crop box with rule-of-thirds grid that can extend beyond image bounds (margin fill).
- **4-Corner Perspective Warp**: Interactive 4-corner pin manipulation (TL, TR, BR, BL) using bilinear homography triangle mesh mapping to straighten skewed documents and photos.

### 8. Smooth Rotation Ruler
- Horizontal scrub ruler with sub-degree numerical readout, `0° Reset` button, and `↺ -90°` / `↻ +90°` steppers.

### 9. Sanitized File Export
- Supports WebP, JPEG, and PNG.
- Exports with clean naming conventions: `[image-name]_[width]x[height].[ext]`.
